### Advanced Scientific Calculator

A robust, high-precision command-line scientific calculator built to handle everything from basic arithmetic to complex engineering and statistical computations.

*   **Basic Arithmetic** - Addition, subtraction, multiplication, division, modulo, and exponents.
*   **Trigonometric Functions** - Sine (

### 🛠️ Tech Stack

*   **Language:** Python 3.x (or your chosen language)
*   **Libraries Used:** Math, NumPy (Optional, if used for matrices)
